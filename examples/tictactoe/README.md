# Tic-tac-toe

An example specification of a noughts-and-crosses type game inspired by a [VDM-SL example](https://www.overturetool.org/download/examples/VDMSL/Tic-tac-toeSL/index.html) developed by Nick Battle.

See also BDS example in [Azuki](https://github.com/anaplan-engineering/azuki/tree/develop/tictactoe)
