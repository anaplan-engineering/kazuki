# Alarm

A translation of the Alarm example from the VDM-SL book [1].

This is the first implementation of the example, in a functional style.

The example is inspired by a subcomponent of a large alarm system developed
by IFAD A/S. It is modelling the management of alarms for an industrial
plant. The purpose of the model is to clarify the rules governing the duty
roster and calling out of experts to deal with alarms.

[1] J. Fitzgerald and P. G. Larsen, Modelling Systems: Practical Tools and Techniques in Software Development, 2nd ed. 
Cambridge: Cambridge University Press, 2009.
